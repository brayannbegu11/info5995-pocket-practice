# INFO5995 Pocket Practice

A mobile-friendly single-question-at-a-time revision site for INFO5995.

- Four custom mock papers with ten questions each.
- Forty-one deduplicated instructor questions.
- Chinese explanations with optional English translations.
- Progress saved separately for each paper in the current browser.

## Run locally

Open `index.html` in a modern browser, or serve this directory with a static web server.

## Publish with GitHub Pages

The included GitHub Actions workflow can deploy this static site. After reviewing the repository contents, enable Pages with GitHub Actions in **Settings → Pages**, then run **Deploy GitHub Pages** from the Actions tab.

The page is intended to be public when deployed. Do not add personal data or credentials to this repository.
